🚨 COMMON ISSUES & SOLUTIONS

Issue: "manim not found"
  Solution: pip install manim

Issue: "ffmpeg not found"
  Solution: sudo apt-get install ffmpeg (Linux)
           brew install ffmpeg (macOS)

Issue: "Video is blurry"
  Solution: Use -pqh flag instead of -pql

Issue: "Takes forever"
  Solution: Use -pql for testing, -pqh only for final

Issue: "No output"
  Solution: Check terminal for errors, reinstall dependencies

See INSTALLATION.md for more troubleshooting!
